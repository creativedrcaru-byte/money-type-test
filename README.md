# 머니타입 검사

원본 문항을 [가], A~H, [나]의 10개 페이지로 나누어 선택하는 반응형 진단지입니다.

- [가] 1~8번은 각각 A~H에 1점씩 더합니다.
- A~H 그룹의 10개 항목은 해당 알파벳에 더합니다.
- [나] 91~98번은 각각 A~H에 1점씩 더합니다.
- 유형별 최고 12점이며, 최고점이 같은 유형은 모두 표시합니다.
- 원본의 빈 9번과 90번은 선택 항목에서 제외했습니다.
- 선택 내용은 현재 브라우저 탭의 세션에 저장되며 외부로 전송하지 않습니다.

정적 파일로 동작하며 GitHub Pages에서 배포할 수 있습니다. 채점 검증: `npm test`.
